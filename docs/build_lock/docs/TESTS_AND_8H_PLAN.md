T0 = actual start after choosing this plan. Deadline = earlier of T0+8 hours and the actual organizer deadline. This document does not restart the event clock. Four parallel developers do not provide 32 independent hours of integration.

## Technology timeboxes

Jev account/call: 15 minutes to establish access. Qdrant plus embedding: 20 minutes to complete a tiny query. LangSmith: 10 minutes for a masked test trace. Signature/C2PA: at most 20 minutes *after* P0, otherwise NOT_CHECKED. No last-hour API provider switch.

A failed gate selects the documented fallback and changes the feature-status board. It does not authorize fake traces, fake embeddings or fake model answers. At least one model-assisted extraction/planning function must actually run before describing the build as a demonstrated AI pipeline.

## Critical tests to implement in the app

1. A buyer and seller copy with the same event count as one transaction.
2. Same uploader, different hashes -> no independent corroboration claim.
3. Same supplier invoice number under different issuers -> no global duplicate accusation.
4. Identical amount with wrong buyer/issuer -> blocked link.
5. Invoiced amount is not recorded as settled cash.
6. Initiated payment -> excluded from settled totals.
7. Part payment before an outstanding balance is due -> no automatic adverse finding.
8. Missing payment mapping or incompatible currency -> comparison unavailable.
9. Two allocations cannot exceed a payment's settled amount.
10. A quantity estimate without accepted procurement scope -> context question, not scored breach.
11. Hypothetical +10% scenario -> no mutation of canonical facts/index.
12. Second-project allocation uses the same material budget and correct source transaction.
13. Wrong-project/unit/period evidence -> rejected or explicit review.
14. Duplicate evidence acceptance -> one revision/action receipt, no double adjustment.
15. Old-version acceptance or request approval -> service rejects it.
16. Current evidence changes -> previous draft approval invalidated.
17. Late valid response -> reviewed normally; no automatic risk penalty.
18. Unknown delivery of a request -> no automatic overdue accusation.
19. Long project duration -> does not clear independent mismatch or reset deadline.
20. No signature/C2PA -> unknown/absent, no “fake” classification.
21. AI-origin marker alone -> no financial-risk points.
22. Prompt injection in PDF -> no extra tools, permission or score mutation.
23. Company A requests Company B's case -> forbidden before model/retrieval.
24. Company prompt bundle excludes counterparty tax status/internal risk.
25. Invented evidence ID or fabricated quotation -> reject draft/fallback.
26. Model/Qdrant/LangSmith outage -> core facts unchanged and fallback labelled.
27. Graph resume after app restart -> correct case/version/actor; no repeated side effect.
28. File-size/page/type/path limits -> controlled failure without processing arbitrary content.
29. Evaluation truth or expected-result filenames -> excluded from runtime input.
30. Unsupported law or legal deadline -> no operative company notice.

The actual implemented test report may be smaller; never claim these 30 passed merely because this checklist exists.

## Evaluation

Record extraction exact-field correctness, match precision/recall on the defined synthetic cases, critical wrong-link count, scenario arithmetic correctness, unresolved/unknown routing, number of unsupported dossier statements, actual model latency, and end-to-end completion rate. Measure time on a small matched manual-versus-assisted task only if a teammate really performs both with order varied. Label participant familiarity and small sample size.

Targets are acceptance intentions, not achieved results. The reference tests included in this pack establish only their local functions—not app auth, live Jev accuracy, LangGraph correctness or invoice authenticity.

## Cut order

Cut voice, vehicle/construction expansion, rich cryptographic UI, extra graphs, ML training, scanned-image OCR and cloud deployment before sacrificing the clarification/revision loop. Preserve local Qdrant/Jev/LangGraph adapters with honest feature modes; cut a failing external integration from the claimed demo, not from the limitation report.

If hour 3 arrives with no integrated slice: keep one French native-text invoice family, deterministic reference record, manual validated context, three scenarios and a template dossier. No new schema.

If hour 5 arrives with broken live acceptance: manual evidence entry through the same permission and allocation controls is acceptable. If those controls themselves are broken, disable writes rather than fake them; make the limitation explicit.
